# mitre-attack

Queries that summarize what's been observed in the environment against the MITRE ATT&CK matrix.

| Query | Description |
| --- | --- |
| [`mitre-attack-tactics-observed.kql`](./mitre-attack-tactics-observed.kql) | Events mapped against MITRE ATT&CK Tactics that have been observed in the environment, with percentage of total. |
| [`mitre-attack-techniques-observed.kql`](./mitre-attack-techniques-observed.kql) | Events mapped against MITRE ATT&CK Techniques that have been observed in the environment, with percentage of total. |
